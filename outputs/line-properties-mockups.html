方案 A · 现代检查器

  • 分区标题 + 分隔线，本线 / 摆放 / 按需组层级一眼可辨
  • P1 / P2 端点独立卡片，蓝点标记，解决原面板 P1/P2 挤在一起的问题
  • 「连接到」改为虚线高亮拾取按钮，不再是像禁用态的灰输入框
  • 线型用真实线条预览，下拉类型改分段按钮，少一次点击
  • 「当前实际长度 / 世界角度」改成派生值灰条，和可编辑字段区分开
  • 选中态统一为白底浮起，替代原来的浅黄底

方案 B · 深色专业 CAD

  • 参考 Blender / AutoCAD 的可折叠分区，分区可以收起，信息密度高
  • 整体面板更窄（380px），适合停靠在画布侧边
  • P1/P2 端点用左侧蓝条卡片区分，结构清晰
  • 数字输入框普遍变窄，单位外露（cm / °），专业感强
  • 派生值（世界角度）用等宽绿字，一眼认出是计算结果
  • 深色主题在低光环境/长时间工作下更护眼；若整个软件是浅色主题则不建议单独用

方案 C · 清爽卡片

  • 每个分区是独立白卡片浮在浅灰底上，边界最清晰
  • 按钮风格完全统一为 Ant Design 式 radio 组，选中态是实心蓝，语义最明确
  • P1/P2 端点用蓝色徽章标识，「拆开」是文字链接，弱化次要操作
  • 底部按钮右对齐，符合常规对话框习惯
  • 面板最宽（420px），空间最宽松；代价是占用画布侧边空间较多
  • 与 Element / AntD 类组件库风格一致，将来若做 Web 版几乎零成本迁移
