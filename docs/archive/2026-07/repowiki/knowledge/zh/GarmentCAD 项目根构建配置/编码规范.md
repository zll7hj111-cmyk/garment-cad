- 每个功能模块在 `src/` 下按职责划分独立子目录（parametric、ui、tools、canvas、geometry、app），源文件按头文件/实现文件分离命名。
- CMake 中每个可执行目标通过 `add_executable` 显式列举所有 `.h/.cpp` 源文件，而非使用通配符或 `file(GLOB ...)`。
- 测试目标采用 `add_executable(test_xxx ...)` + `add_test(NAME test_xxx COMMAND test_xxx)` 的 Qt Test 模式，仅链接被测模块所需的头文件与实现。
- Qt 相关编译选项通过 `CMAKE_AUTOMOC/AUTORCC/AUTOUIC` 全局开启，避免手动调用 moc/uic/rcc。
