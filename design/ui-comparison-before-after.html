改动说明

  1. 左竖线：斑马纹 → 类型色。现状偶数行蓝 #2F6FED / 奇数行橙 #F59E0B 交替，颜色不携带任何信息，且与 piece4 钴蓝、warning 琥珀撞色。改后：变量=piece1 碳灰、公式=piece2 深青、测量=piece3 陶土、关联=piece4 钴蓝——竖线变成「类型图例」，一眼分辨卡片性质。
  2. 数值：13px → 15px Semibold。CAD 用户最需要的是数值。现状数值与名称同字号同字重，视觉焦点分散。改后数值成为卡片第一焦点，单位缩至 10px text3 退居元信息位。
  3. 子页签下划线：灰 → piece 类型色。激活页签下划线用对应类型色，与卡片竖线、名称 chip 形成颜色闭环。
  4. 名称 chip 文字着色。现状 chip 只有边框是 piece 色、文字是默认黑。改后文字同步着色，类型识别更强（此改动已在图中体现，未单独标号）。
  5. 删除按钮幽灵化。现状 setVisible(false) 直到 hover 才出现——键盘 Tab 永远无法聚焦，屏幕阅读器不可见。改后常驻 25% 透明度的 ✕ 轮廓，视觉零跳变且键盘可达。
需要你拍板：方案 A（类型色竖线，本图右侧所示）vs 方案 B（中性化：偶数行 #CBD2DC 灰、奇数行无色）。方案 A 增加信息密度、消除 2 个多余色相；方案 B 改动最小但浪费了一个信息通道。

改动说明

  1. 分组标题：裸粗体 → 等宽代号 + 发丝线。现状「基本/几何/外观/端点」只是加粗文字，分组边界不清晰。改后为 GEOMETRY 等宽 10px 大写代号（letter-spacing 1.5px）+ 中文标题 + 底部 1px 发丝线。此模式已在 FormScaffold::makeFormGroupHeader 实现，推广到此处即可。
  2. 「填入」按钮内嵌化。现状「填入」按钮与只读值「24.38 cm」并排，语义模糊——不知它是作用于值还是填充别的字段。改后成为输入框右侧的内嵌幽灵图标 ⇩，hover 出 tooltip「从画布拾取长度」，语义无歧义。
  3. 端点卡片统一为 CardBase 语言。现状 P1/P2 卡片样式与全局卡片不一致。改后采用 1px 边框 + 4px teal 左竖线（连接语义色）+ 等宽代号标题 P1 · START，与画布端点的 teal 附着色呼应。
  4. 底部按钮层级 + 右对齐。现状「撤销全部 / 关闭」左对齐平铺、同权重——用户不知道哪个是主操作，且破坏性的「撤销全部」与安全的「关闭」视觉等价。改后：「关闭」升为实心黄主操作并右置，「撤销全部」降为次级描边按钮（hover 转 danger）。
  5. 表单栅格统一为 88px 标签列。现状各分组标签宽度不一（62px 左右浮动）。改后固定 88px 右对齐标签列，跨对话框一致。

改动说明

  1. 激活图层：蓝 tint → 黄 tint。现状激活卡用 #2F6FED 蓝底 + 蓝色左竖线——但「当前激活」本质是强调信号，按三分层纪律应收归 accent 黄色系；蓝色应留给「关联类型」。改后：accentTint 浅黄底 + accent 黄左竖线 + accentStrong 描边，与工具激活态、焦点态统一。
  2. 段行增加 serial 编号。现状段行只有名称，无法与画布实体、状态栏编辑条的 L3 徽章对应。改后右侧增加等宽 10px serial 标签（与 QLabel#serialBadge 同款：墨底黄字 / 灰底样式），形成「面板 ↔ 画布 ↔ 编辑条」三处编号统一。
  3. 隐藏段降对比但保交互。现状隐藏段仅有眼睛图标变化。改后整行文字转 text3、眼图标转空心，但仍可点击选中——符合架构原则「visible=false 是纯视觉属性，不影响交互」。
  4. 硬编码色令牌化。现状此面板有 4 处硬编码色（眼睛 #2E86C1、闭眼 #B0BEC5、折叠箭头 #7F8C8D、漏斗 #6C3483），主题切换时不跟随。改后全部走新增的 iconColor 语义令牌。

改动说明

  1. 编辑条独立条带化。现状 SegmentEditBar 内嵌在 ElaStatusBar 内（被迫硬编码 24px 高度对抗 ElaLineEdit 的 35px 默认高度）。改后为状态栏上方的独立条带：accentTint 浅黄底 + accentStrong 1px 描边，明确标识「你正处于创建后编辑态」，与坐标/缩放信息彻底分离，切换时零布局跳动。
  2. 诊断徽章左侧化。现状诊断信息混在工具提示文字中易被淹没。改后为状态栏右侧的 danger 实心徽章 ⚠ 3，点击弹出明细菜单；健康时完全不占位（hide 而非隐藏占位）。
  3. 新增瞬时反馈通道。保存成功 = success 对勾 + 文件名 2s 淡出；撤销/重做 = 状态栏瞬时文字「已撤销：创建线段」1.5s 还原。现状这两类操作无任何显性反馈。
实现提示：以上 4 个场景的改动均可沿现有 token 单源机制推进，无需引入新样式系统。主要落点：CardBase.h/.cpp（场景 1）、LinePropertyDialog.cpp + FormScaffold.h（场景 2）、LayerPanel.cpp（场景 3）、SegmentEditBar.cpp + MainWindow.cpp（场景 4）。
