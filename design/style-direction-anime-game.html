WildWind Pattern · Style Direction Exploration

二次元风格方向探索

从 Endfield 工业工具语言，转向有情绪、有质感的二次元视觉体系。参考锚点：《明日方舟》的数据终端美学 与 《重返未来：1999》的复古秘仪美学。本页拆解两者的视觉语法，评估其在 CAD 高密度场景下的适配边界，并给出三个可落地方向。

01视觉语法拆解 两个游戏的语言本质差异

这两个参考看似都是「二次元」，实则走的是几乎相反的两条路。理解这个差异，是判断它们能否嫁接到 CAD 的前提。

维度《明日方舟》 Arknights《重返未来：1999》 Reverse: 1999
核心信条克制 — 「所有视觉内容都承担功能」，装饰元素仅用于分割层级，不承载信息铺陈 — 「复古 / 神秘学 / 电影感 / 20 世纪」，装饰本身即是内容
色彩逻辑大面积中性色（灰白黑）+ 少量功能色 + 极少量警示色。招牌是「酸橙色信笺」：深灰底 + 高彩度化学绿 + 极细亮色描边极深墨底 + 暖金 / 复古橙。饱和度不高，靠「暗」与「金」的对比营造低调奢华
几何语言斜切角（chamfer）、矩形切割、数据化辅助线、工业网格、参数化图形、工程制图式排布Art Deco 对称几何、装饰性双层边框、拱形、放射线、菱形、拼贴
字体汉字黑体 / 方折造型体；英文与数字几乎清一色等宽字体（终端机般的机械序列感）衬线体标题（古典、有文学性）+ 无衬线正文；大量装饰性分隔与烫金质感
质感磨砂玻璃 / 亚克力（Fluent 质感）、扫描线、噪点化、马赛克切分、背景模糊分层纸张纹理、胶片颗粒、做旧、烫金、老照片色偏
构图非对称构图，「参差感」— 用不对齐制造视觉流动与方向指向电影感居中构图，对称庄重，留白给看板角色
关键判断

方舟的底层其实是「高信息密度的工程终端」——它的设计团队反复强调「真正优秀的 UI 不是减少信息量，而是在高信息密度下依然保持清晰秩序」。这与 CAD 的需求几乎完全同构。而 1999 的底层是「沉浸叙事」，靠装饰与氛围打动人，与「精确读数」存在结构性冲突。

换句话说：方舟好看是因为它把工具做到了极致；1999 好看是因为它把装饰做到了极致。

02CAD 场景的适配边界 什么能要，什么必须拒绝

服装 CAD 有四条硬约束，任何风格转向都不能突破。这决定了两个参考的可用边界。

CAD 硬约束对方舟元素的影响对 1999 元素的影响
数值必须瞬时可读
（高频扫读，不能有任何干扰）		✓ 等宽数字、工程制图式排布、参数化标注 —— 天然契合，这是方舟的看家本领✗ Art Deco 装饰边框、花纹分隔线会与数字争夺注意力；衬线数字在小数位辨识上弱于等宽体
长时间使用不疲劳
（打版师一天 8 小时）		✓ 低饱和大面积中性色 + 极少量高亮 —— 官方自述「长时间保持视觉舒适度，几乎不产生视觉疲劳」△ 暗色+暖金本身舒适，但持续暴露在高密度装饰纹样下会增加认知负荷
画布是主体，UI 是配角✓ 深灰底让画布线条更突出，UI 自然退后✗ 华丽边框会抢画布注意力——打版时用户眼睛要盯线条，不能被金色花纹拉走
刷新性能敏感
（拖动时每帧重绘）		△ 斜切角 / 描边 / 网格 = 静态绘制，零运行时代价；但真磨砂玻璃需要背景模糊抓帧，在频繁重绘的面板上是性能陷阱✗ 双层边框、纹理叠加、做旧质感多为位图或多层自绘，重绘成本高
给你的判断

你说「降低工具感，多一些漂亮的感觉」——我的诊断是：问题不在缺装饰，而在当前配色太冷、太平、太素。蓝图灰 #ECEFF2 + 白面板 + 信号黄，这套配色在功能上没问题，但它没有质感、没有情绪、没有「材质」。

正确的解法是加「质感」而不是加「花纹」：换深色基底、换有情绪的强调色、加极细描边与斜切几何、铺一层几乎看不见的扫描线与噪点。这些不改变信息密度，却能让界面从「工具」变成「有性格的终端」。

1999 的 Art Deco 装饰边框如果照搬，会在两周后让你怀念现在这个朴素的版本。

04落地路径 以方向 C 为例

现有 ThemeTokens 单源架构是这次改造的最大资产——换风格不需要动任何业务逻辑，只需重做色板与少量自绘。

改造清单与成本

改造项成本说明
色板重做
Theme.h/.cpp		低替换 light()/dark() 两组 token 值，并将默认模式改为 Dark。42 个 token 结构不变，QSS 生成器自动跟随。这是收益最高、成本最低的一步
斜切角
CardBase::paintEvent		低卡片已有自绘 paintEvent 骨架，把 drawRect 换成 drawPolygon（右上切 7px）即可。静态绘制，零运行时代价
顶部渐隐金线
全局 QSS		低面板/对话框顶部 1px 渐变描边。Qt 下用 border-image 或自绘一行。视觉收益远大于成本
工程代号标签
VAR / FML / MSR		低子页签文字改为等宽大写代号，与 FormScaffold::makeFormGroupHeader 已有模式一致
扫描线 / 噪点底纹中需要生成一张 4px 高的平铺贴图（运行时 QImage 生成或 qrc 内置），通过 QSS background 平铺。注意：透明度要压到 2% 以下，否则干扰读数
Ela 控件去圆角
ElaWidgetTools		中Ela 组件默认圆角偏大（与斜切直角语言冲突）。现有 PATCH_COMMAND 机制已能打补丁，追加一条即可
画布配色同步
CanvasStyle		中CanvasStyle 与 ThemeTokens 手工同步，画布底色、网格线、piece 填充需一并调整为深色版。注意 displayColor 的暗色提亮逻辑要重新校准
真磨砂玻璃不推荐Qt Widgets 下需 QGraphicsBlurEffect 抓取背景，在每帧刷新的画布旁是性能陷阱。替代方案：半透明纯色 + 噪点贴图模拟，视觉接近但零代价
Art Deco 装饰元素不推荐双层边框、花纹、角标需大量自绘，重绘成本高且干扰读数。仅建议用于「关于」对话框与欢迎页
建议路径

第一步（1~2 天）：只改 ThemeTokens 色板 + 默认切 Dark + 顶部渐隐金线。这一步就能拿到 80% 的观感提升，且完全不动逻辑，随时可回滚。

第二步（3~5 天）：加斜切角 + 工程代号 + 扫描线贴图。此时风格语言基本成型。

第三步：校准画布配色与 Ela 圆角。做完这一步才是完整交付。

先用第一步的「低成本试妆」验证方向对不对，再决定是否投入后续——这比一次性重做要稳妥得多。
