00全面审核结论（现状问题清单）

对现有全部界面逐面板走查后的核心发现。严重度：P0 = 信号混乱/规则冲突，P1 = 体验受损，P2 = 打磨项。

面板 / 区域严重度审核发现
全局色彩信号P0色相过载：信号黄 accent + 偶蓝/奇橙行竖线 + 4 个 piece 类型色 + 4 个语义色（成功/警告/危险/青）同屏可达 9+ 色相，「什么颜色代表什么」没有单一答案。蓝橙竖线为历史拍板值（Theme.h 注明「终末地下待用户重拍板」），与「信号黄唯一强调色」的设计语言直接冲突。
双重导航P0主窗口顶部 ElaTabBar（画布/变量/图层/组）与面板悬浮窗大标签构成两级、两处、语义重叠的导航：「变量/图层」既是主窗口标签又是悬浮窗开关，选中态需要 syncPanelTabs 双向同步，用户难以建立稳定心智模型。
变量面板页签P15 个平级页签（变量/公式/关联/测量/组件）信息架构扁平：「关联/测量」本质是只读结果，「组件」是工作组，与可编辑的「变量/公式」混排，缺少「输入 → 派生」的层级表达。
卡片视觉层级P1五类卡片共享 CardBase 骨架是好的，但序号、名称 chip、值、🔒、删除钮在 header 一行内密度过高；值（最重要的信息）与名称同字号同字重，视觉焦点不突出。
线条属性对话框P1（对照 panel_shot.png）分组标题（基本/几何/外观/端点）样式弱、间距节奏不一致；「填入」按钮与「24.38 cm」只读值并排，语义模糊；端点 P1/P2 卡片样式与全局卡片语言不统一；底部「关闭 / 撤销全部」层级平铺，主操作不明。
状态栏P1状态栏承载坐标 + 缩放 + 工具提示 + 诊断 + SegmentEditBar + SmartPenPreInputBar 六种信息，编辑态与只读态切换时布局跳动风险高，诊断警告（danger）易被淹没。
暗色模式 piece 色P2dark() 中 piece1–4 变为另一组色相（蓝灰系），亮/暗两模式下「公式 = 深青」这类类型记忆断裂，跨模式一致性弱。
圆角与形状纪律P2RadiusPill = 4 的命名与「禁胶囊」纪律自相矛盾；部分对话框（Ela 组件默认）圆角大于 token 规定，直角工业感不统一。
总体判断：设计 token 体系（ThemeTokens 单源、字号/间距/圆角阶梯、等宽数字纪律）基础扎实，不需要推翻。本次 redesign 定位为 「Endfield 2.0」演进：保留骨架，收敛色彩信号、重构导航层级、统一卡片与表单语言。

01设计原则（Redesign 总纲）

  • ① 一个强调色。信号黄 #FFDE00 是唯一的「动作/选中/焦点」信号。任何其他颜色只能是「实体身份色」或「语义状态色」，绝不兼任强调。
  • ② 颜色三分层。强调色（黄，全 App 仅 1 个活跃实例）→ 类型色（piece 家族，标识数据类别）→ 语义色（绿/琥珀/红/青，标识状态）。三层不混用。
  • ③ 一条导航线。主窗口标签只负责「画布 ↔ 面板」开关；面板内部页签负责内容分类。消除双向同步的镜像导航。
  • ④ 纸面与墨。画布是纸（#ECEFF2 蓝图灰），面板是图纸夹（白面 + 1px 发丝线），直角为主，功能圆角 ≤ 4px。
  • ⑤ 数字不抖。一切读数/输入用等宽字体 + 固定位宽，拖动联动刷新时布局零位移。
  • ⑥ 密度服务于手。CAD 是高频工具：信息密度优先于留白美学，但每个交互目标 ≥ 24px 高度。

2.5 行竖线：双色 → 类型色 ✎（建议重拍板项）

现状冲突：偶数行蓝 #2F6FED / 奇数行橙 #F59E0B 竖线是历史拍板值，但橙色 #F59E0B 与 warning 琥珀色 #B45309 同族易误读，且蓝橙双色与信号黄争夺注意力，是 P0 色彩过载的主因。
Redesign 方案（二选一，需用户拍板）：
方案 A（推荐）：竖线改标「卡片类型」——变量=piece1 碳灰、公式=piece2 深青、测量=piece3 陶土、关联=piece4 钴蓝。竖线从「装饰性斑马纹」升级为「类型图例」，与页签颜色呼应。
方案 B（保守）：保留斑马纹语义但去彩色化——偶数行 #CBD2DC 中性灰、奇数行无色（仅靠 surface3 条纹底），彻底退出色彩信号层。

5.5 对话框通用规范

  • 标题栏：ink 实心底 + 白字，左对齐 英文代号 + 中文标题，右置 ✕。
  • 内容区：内边距 14–16px，分组间距 18px，分组标题 = 等宽大写代号 + 底部发丝线。
  • 按钮条：surface3 底 + 顶部分隔线，按钮右对齐，主操作最右。
  • 删除影响确认（DeleteImpactConfirm）：九项计数用「语义色数字 + 说明」表格化呈现，danger 仅标真正破坏性项，避免整框红色恐吓。

5.6 Tooltip / HUD

  • Tooltip：反转面（ink 底 #F8FAFC 字）+ 等宽数值，延迟 400ms，无动画（沿用 ElaMenu 去动画纪律）。
  • 画布 HUD（AngleHud/预输入）：半透明 ink 85% 底 + 黄字读数，贴光标右下 16px 偏移。
